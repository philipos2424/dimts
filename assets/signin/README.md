# Provider sign-in artwork

- `google.png` and `google-ios.png`: unmodified light rectangular sign-in buttons at 4x from Google's official [asset archive](https://developers.google.com/static/identity/images/signin-assets.zip), downloaded 2026-10-13. See [branding requirements](https://developers.google.com/identity/branding-guidelines).
- `apple.png`: unmodified 3x image from Apple's [button generator](https://appleid.cdn-apple.com/appleid/button?color=white&border=true&height=48&width=216&type=sign-in&locale=en_US&border_radius=4&scale=3), downloaded 2026-10-13.

The component preserves the image aspect ratio and supplies an accessible text label. These are provider trademarks used solely to identify their sign-in flows.
